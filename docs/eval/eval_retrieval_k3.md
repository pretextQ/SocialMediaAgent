# RAG 检索质量报告

> recall@k = 命中期望文档 / 期望文档数；precision@k = 命中 / **实际返回条数**；
> MRR = 第一个命中文档排名倒数；hit_rate = 至少命中一个的用例占比。
> 本评测现场从 seed 文档构建内存知识库，默认 HashEmbedder（确定性），**不需要 LLM 密钥**。
